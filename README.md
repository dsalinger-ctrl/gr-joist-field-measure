# Gila River joist field measurements

A phone form for I-5 Design | Build field measurements of existing open-web steel joists at **Gila River Lone Butte Casino** (project 5291), in the D01, D11, and D05 areas.

Open the page, fill in each lettered measurement (A–H) while looking at the FM-01 reference sheet, add photos with the tape in the shot, and tap **Make PDF**. On a phone you can also **Share PDF**.

Progress is saved in the browser on that phone (localStorage). Nothing is uploaded to a server. There is no login.

This repository contains only the form and the FM-01 field sheet image. It does not include other project documents or personal data.

Live site: https://dsalinger-ctrl.github.io/gr-joist-field-measure/
